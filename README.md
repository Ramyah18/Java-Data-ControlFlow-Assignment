# Java Data & Control Flow Analyzer

This repository contains my completed assignment for the Java Data & Control Flow Analyzer project. It includes two Java programs:

## Exercise 1: Trip Cost & Fuel Analyzer
- Calculates gallons needed, total fuel cost, cost per mile, and cost per passenger.
- Validates user input and formats output to two decimals.

## Exercise 2: Paycheck & Overtime Calculator
- Computes regular pay, overtime pay, retirement deductions, and net pay.
- Includes input validation and formatted pay stub output.

## Included Files
- TripCostAnalyzer_Starter.java
- PaycheckOvertime_Starter.java
- Reflection (150–200 words)
- Screenshots of code and console output

## Purpose
This project demonstrates the use of:
- Variables and primitive data types
- Arithmetic operators
- Control flow (if/else)
- User input handling
- Type conversion
- Formatted output
